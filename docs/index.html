PolePlex

A minimalist AUR package downloader

Download PKGBUILDs from the Arch User Repository with zero bloat.

$ curl -fsSL https://anomalyco.github.io/poleplex/install.sh | bash
poleplex s firefox — Search AUR
poleplex i spotify — Package info
poleplex d yay — Download a package
poleplex r yay — Remove from cache
poleplex u — Update all
